## 核心要求

做一个**交互式 HTML 业务流程地图**，把 SCAL 从采购到结案的端到端流程可视化出来。

### 主链路（7 个阶段，线性）

```
采购 → 收货 → 质检 → 称重 → 投料 → 配方产出 → 结案
```

业务逻辑：
1. **采购** — 创建采购单，申请条码，分发标签
2. **收货** — PDA 扫码入库，生成入库单
3. **质检** — 抽样标签→送检→检验判定→放行/滞留
4. **称重** — 物料投前称重确认，余料退回称重
5. **投料** — 按工单将称重后的物料投入产线/设备
6. **配方产出** — 工单启动→设备启动→配方执行→成品/半成品产出
7. **结案** — BPR 记录归档，工单关闭

### 交互设计

- **第一屏**：7 个阶段从左到右紧凑排列，每个阶段下面露出子流程小标签
- **点击阶段**：展开子流程、连接线、系统泳道
- **每个子流程节点可展开**：展示归属系统（BS/CS/PDA）、源码模块、数据库表、存储过程、Demo 页面链接
- **风格**：商务简洁、高信息密度、无装饰噪音

### 硬性要求

- 每个流程步骤必须**追溯到实现代码**（不能凭空画图）
- 跨系统交接点必须明确标注
- 有 Demo 页面的流程要提供可点击链接
- 7 个阶段的顺序和子流程**必须从源码验证**，不能凭名字推断

## 附：原始阶段顺序说明

正确的生产逻辑：

```
称重（第4阶段） → 投料（第5阶段）
```

先称料确认重量 → 再投料到产线设备。称重是投料的前置条件，不是投料的子步骤。
